## Default Permission

Allows showing a file in Quick Look.

#### This default permission set includes the following:

- `allow-preview`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`quicklook:allow-preview`

</td>
<td>

Enables the preview command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`quicklook:deny-preview`

</td>
<td>

</td>
</tr>
</table>
